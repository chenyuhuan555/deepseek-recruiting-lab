# 招聘记忆实验室

2026-11-03

## 目标与取舍

让使用者直接观察岗位版本、反馈适用范围和证据复核，而不是只阅读代码。采用无依赖静态 HTML/CSS/JavaScript，便于本地运行和独立托管。浏览器实现映射 Python 示例的规则，不直接执行 Python，也不调用模型或 LinkedIn。

## 页面

- 全宽、浅色工作台，深绿强调色；项目切换和重置位于顶部，没有侧边导航。
- 岗位修订：客户原话、结构化条件、变更预览、人工确认、新版本；提供旧版本冲突演示。
- 反馈范围：切换虚构项目、顾问和日期，逐条解释记录的纳入或排除原因；记忆不自动成为岗位条件。
- 证据复核：展示虚构材料原话与判断缺口，允许人工标记支持、不支持、信息不足；岗位变更后要求重新复核。
- 数据只保留在当前页面内存，刷新或重置即清空。来源与核心代码有可点击入口。

## 实施与验证

1. 先写浏览器规则测试，验证保留旧条件、冲突、摘录、显式取消及范围和有效期过滤；运行确认缺少实现，再补最小实现。
2. 新建 `examples/scoped-memory/web/`，拆分规则、虚构数据、界面与样式。新增复核状态随岗位版本失效的测试。
3. 运行 Node 规则测试和已有 Python 测试；在浏览器检查三页交互、错误提示及窄屏布局。
4. README 增加运行说明；从独立托管目录发布，保留来源，明确实现边界。

成功标准：新增条件不丢旧条件，旧草稿不能覆盖新版本，不同项目记忆有可解释的过滤结果，证据确认不能冒充自动核实，手机页面无横向溢出。
