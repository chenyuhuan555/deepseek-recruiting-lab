## 问题与取舍

- 原先浅灰绿背景、白色边框面板和小标签反复出现，内容权重被拉平。
- 首屏改为有明确断行的中文标题和原创档案关系图，表达版本、范围与来源。
- 暖纸白、墨黑、电蓝成为统一规则；编辑区、档案区和历史记录采用不同密度，减少重复容器。
- 不引入整页深色海报、照片、外部字体、动画或依赖。网格仅留在主视觉，表单保持干净。
- 小屏压缩展示区，保留项目切换和全部操作入口。虚构数据和能力边界继续显示。
