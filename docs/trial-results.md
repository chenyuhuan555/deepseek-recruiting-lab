## Windows 测试结果

完整测试为 1154 项通过、43 项失败，另有 17 个未捕获错误。错误涉及 POSIX 命令缺失、Windows 符号链接权限及路径等差异。

为测试进程补充 Git 自带的 Unix 工具目录后，命令与环境两组定向测试为 25 项通过、7 项失败，仍包含包装脚本执行、进程信号、路径表示与符号链接问题。该结果不是完整测试重新通过。

本地面板启动成功不等于 Windows 上的端到端执行已经可靠；继续自动工单试验前，需要解决或改用符合依赖要求的执行环境。

## 为什么同一 GitHub 账号默认不能自己发任务、自己接

原版将与执行账号相同的消息作者标记为 `human: false`，默认策略会将此类消息以 `not_human` 拒绝。这有助于防止将自己的回复再次当成用户任务。把同一账号加入人的允许列表，不会改变该作者分类。

这属于本原型的接单设计，不能概括成 GitHub 或 DeepSeek 模型必须使用两个账号。原版默认的 GitHub 流程仍应区分发起人与执行身份；本轮没有修改这一机制。

固定版本源码：[github-trigger.ts](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/6337fc823ce20251c8de8085948165c81aaa701e/src/sources/github-trigger.ts#L62)、[policy.ts](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/6337fc823ce20251c8de8085948165c81aaa701e/src/policy.ts#L171)。
