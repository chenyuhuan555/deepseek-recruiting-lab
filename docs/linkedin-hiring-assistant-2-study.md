# LinkedIn Hiring Assistant 2：业务研究与可借鉴的设计

查阅日期：2026-11-03。依据公开官方资料，没有付费席位实操；本页将官方描述、个人推演与本项目的实现状态分开。

## 1. 产品进展需要怎样理解

LinkedIn 于 2026-09-29 宣布第二代，计划从11月起为现有英文版客户逐步更新。查阅时产品页仍将部分第二代能力标为 Coming soon，因此不能认定每个客户已获得全部能力。[官方公告](https://news.linkedin.com/2026/hiring-assistant-2) · [产品页](https://business.linkedin.com/hire/hiring-assistant)

Hiring Assistant 是 Recruiter 的附加产品。基础产品、第二代新增能力和账户可用性应分别确认；也不能把现有语言支持直接当作第二代所有功能的语言覆盖。[使用资格与说明](https://www.linkedin.com/help/recruiter/answer/a7109304)

## 2. 有用的产品机制

| 官方资料描述的机制 | 对猎头工作的问题启发 | 本项目建议 |
| --- | --- | --- |
| 项目中整理岗位条件，并能继续修改和重评 | 客户要求会变化，单次生成报告难以追踪 | 为每次已确认变更保留版本与依据 |
| 持续记忆与个性化 | 历史习惯能减少重复沟通，也可能误导新项目 | 明确反馈范围，重新使用前检查有效性 |
| 综合资料、简历和预筛等信息 | 相同的能力判断可能有不同证据强度 | 每项判断展示出处、缺口和核实状态 |
| 根据具体候选人反馈调整结果 | “不合适”往往没有说明真正原因 | 保存反馈针对的条件与原话，避免直接推广 |

前两项依据：[产品与使用说明](https://www.linkedin.com/help/recruiter/answer/a7109304)。证据展示和反馈依据：[申请人评估帮助](https://www.linkedin.com/help/recruiter/answer/a7109476)。表中“本项目建议”是独立设计，不代表 LinkedIn 的公开实现细节。

## 3. 记忆应该怎样借鉴

LinkedIn 2026-03-26 的 CMA 工程文章披露了对话、事件、语义和流程记忆，也讨论了信息过期、冲突与上下文归属。这是既有 Hiring Assistant 技术底座的描述，不是第二代完整内部规格。[官方工程文章](https://www.linkedin.com/blog/engineering/ai/the-linkedin-generative-ai-application-tech-stack-personalization-with-cognitive-memory-agent)

我们的设计先从业务范围分开：

- 岗位记录：“本岗位必须主导过上线”，关联岗位和版本。
- 客户记录：“本次暂不接受远程”，附客户、来源、日期与适用范围。
- 顾问偏好：“推荐摘要用三句话”，用于表达方式。
- 候选人状态：“暂时不考虑机会”，单独存放确认日期；不能作为永久意向。

关键原则：一次事件不自动上升为长期规则；历史偏好不直接变成本岗位的硬门槛。来源明确并经人工确认的当前条件，优先于助手推断的历史偏好；若两条明确要求仍冲突，提示顾问确认。

## 4. 把“匹配”和“兴趣”分开

官方第二代介绍分别讨论了岗位契合与候选人兴趣信号，后者参考平台活动、求职意愿设置与消息响应等信息。[官方产品介绍](https://www.linkedin.com/pulse/introducing-hiring-assistant-2-more-advanced-ffdyf)

我们的数据模型应分别记录岗位证据、联系状态与已确认意向。不从技术匹配分数推断候选人愿意沟通，也不从一次回复推断愿意接受机会。身份经过平台验证，同样不意味着技能或项目贡献已得到完整核实。

例如，要求“主导上线”，资料只写“参与上线”，应展示“责任深度待核实”，附原文和面试问题，而不是自动判定满足或不满足。

## 5. 自动动作必须对应具体授权

当前帮助文档说明，打开项目级 instant outreach 后，系统可按已批准的计划自动发送与跟进；关闭时不会自动发消息。因此不能笼统说每条消息都必须逐条点击批准。[项目级触达帮助](https://www.linkedin.com/help/recruiter/answer/a7109304)

本项目先保持纯研究与内部记录。未来若增加外部动作，应分别设计生成草稿、发送、跟进和修改条件的权限；候选人的资料内容不能成为操作授权。

## 6. 效果数字怎么读

官方公告中的减少资料审阅、加快识别等数字属于厂商披露，不代表我们自己的效果，也不宜全部归因于第二代。公告的“预筛中位数6分钟”与“首次回复通常3.5小时”衡量不同环节，不能直接相减作为顾问节省工时。[公告与指标](https://news.linkedin.com/2026/hiring-assistant-2)

我们的验证应记录：顾问总处理时间（含检查纠错）、条件误分类、关键证据遗漏、误排除案例，以及进入后续面试的有效数量。不能用模型测试通过率代替业务效果。

## 7. 先实施什么

第一阶段：岗位版本、带范围的反馈、证据与缺口记录。

第二阶段：验证模型能否提出准确草稿、识别冲突并解释影响，再接入可编辑的人工审核页面。

第三阶段：在有授权的数据范围内尝试任务自动化与系统同步。LinkedIn 的人才网络、行为信号和 ATS 接入不可通过一个通用模型直接复现。
